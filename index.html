Ayuda

¿Qué significa cada símbolo?
  • Óvalo: Inicio y Fin.
  • Rectángulo: Proceso, una acción o cálculo (p. ej. S = A + B).
  • Paralelogramo: Entrada (leer un dato) o Salida (mostrar un resultado).
  • Rombo: Decisión, una pregunta cuya respuesta es Sí o No.
  • Rectángulo con barras: Subproceso, un grupo de pasos con nombre.
¿Cómo se usa?
  • Pulsa un símbolo para añadirlo. Si hay otro seleccionado, aparece debajo y unido con una flecha.
  • Arrastra los símbolos para colocarlos.
  • Doble clic sobre un símbolo o flecha para escribir. Mayús + Intro hace un salto de línea.
  • Para unir dos símbolos, arrastra desde uno de sus puntos azules hasta el otro, o usa Modo flecha.
  • Selecciona una flecha y arrastra su punto central hacia un lado para hacer bucles.
  • Supr borra lo seleccionado. Ctrl + Z deshace.
  • Tu trabajo se guarda solo en este navegador. Para entregarlo, pulsa Descargar imagen.
